# Question 4: NotebookLM Evaluation

This folder documents the practical evaluation of Google NotebookLM for BUS5001 Assessment 3.

## Academic Scenario
A university student uses NotebookLM to study sustainability reporting standards.

## Sources
- GRI 303: Water and Effluents 2018
- GRI 306: Waste 2020

## Experiments
1. Document comparison and source citations
2. Interactive Learning Overview
3. Sustainability Quiz and answer feedback
4. Environmental Standards Mind Map
5. Audio Overview

## Key Findings
NotebookLM supported document comparison, study material generation, quizzes, visual learning and audio learning.

## Limitations
AI-generated explanations may omit technical details or contain inaccuracies. Users should verify important claims against the original GRI documents.
