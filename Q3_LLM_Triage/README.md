/# Question 3: ESG Message Triage

This folder documents the ESG incident classification experiment for BUS5001 Assessment 3.

## Experiment
- LLM: Gemini 3.5 Flash Lite
- Three simulated ESG incident scenarios
- Structured JSON classification
- Python rule-based baseline using Google Colab

## Results
- Issue category agreement: 3/3
- Urgency agreement: 2/3
- Disagreement: Energy waste urgency (MEDIUM versus LOW)

## Limitations
These results measure agreement, not classification accuracy. The sample is small and the baseline uses manually defined rules.
